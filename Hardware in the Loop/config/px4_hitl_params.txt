# ============================================================
# PX4 Parameters for Hardware-in-the-Loop (HITL) Mode
# ============================================================
# Set these via QGroundControl (Vehicle Setup → Parameters)
# OR via MAVLink shell:  param set <NAME> <VALUE>
#
# IMPORTANT: After setting HITL_ENABLE=1, REBOOT the FC.
# The FC will then expect sensor data from the simulator,
# NOT from its real onboard sensors.
# ============================================================
